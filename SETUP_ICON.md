# Durich WMS - Warehouse Management System

## Setup Icon Launcher

Untuk mengupdate icon aplikasi dengan logo Durich, jalankan perintah berikut:

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

Icon launcher akan otomatis di-generate untuk Android dan iOS menggunakan `durich_logo.png`.

## Build & Run

```bash
flutter run
```

## Features

- ✅ Warehouse Management
- ✅ Sales Management  
- ✅ Smooth Animations
- ✅ Global Notifications
- ✅ Form Validations

## Tech Stack

- Flutter 3.6.1
- Riverpod (State Management)
- GoRouter (Navigation)
- Dio (HTTP Client)
